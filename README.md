# Python Mini Projects

Repositorio de mini proyectos creados durante mi formación en Python con Tokio School.

## Objetivo

Consolidar los fundamentos del Módulo 1 mediante programas simples usando variables, tipos de datos, entrada/salida, listas, diccionarios y condicionales básicos.

## Bloques

- Días 3-5: tipos básicos, operaciones e input/output.
- Días 6-8: listas y diccionarios.
- Días 9-10: gestor simple de tareas.
